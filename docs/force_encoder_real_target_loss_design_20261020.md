# 力 encoder 的真机力监督设计

日期：2026-10-20。本文是基于现有代码与保存结果的设计建议，尚未修改训练代码或验证新配方的训练效果。文中的系数是首轮实验起点。

目标是让仿真力的历史表示保留预测对应真机力及其变化所需的信息。沿用 v3 的两个域 encoder 和共享物理量预测头：

```text
Sim 历史力 [32,3] + 历史 dt → E_sim → z [32] ┐
                                             ├→ D_real → 当前及未来真机力 [6,3]
Real 历史力 [32,3] + 历史 dt → E_real → z [32]┘
```

两域输出目标均为 `(F_real[t], ..., F_real[t+5])`，单位 N。输入使用各域自己的训练集归一化统计，输出统一使用真机训练集统计。预测头只能读取 latent，没有实测真机当前力或原始仿真力的旁路。

**仓库中与目标直接相关的位置**

- `scripts/force_predictive_encoder_v3/data.py:118`：`future` 已经是真机未来力，`current` 已经是真机当前力，无需另找当前力标签。
- `scripts/force_predictive_encoder_v3/losses.py:78`：未来差分只比较 `+1→+2 ... +4→+5`，没有预测的当前力，因此不包含 `t→t+1`。
- 同文件 `:86`：历史重建目标取自 `components[:, domain]`，Sim 分支监督的是 Sim 自身力，不是对应真机力。
- 同文件 `:101`：除预测外，还有较强的本域重建、历史差分、频谱、峰值和趋势对齐监督。
- `scripts/train_force_shared_latent.py:250`：配对与片段对齐权重为 1 和 0.5，未来预测权重为 0.2；`:476` 还优先按对齐分数选模型，未来误差仅在前项相等时参与比较。
- `scripts/force_predictive_encoder_v3/train.py:150`：v3 的早停分数仍包含 0.25 倍的本域重建误差，需要随新目标一起调整。

**第一轮建议的主损失**

记 `y_k = F_real[t+k]`、`p_k = D_real(E_domain(history))[k]`，`k=0..5`。模型直接输出六个力值，不用递归积分生成它们。定义 `rho = SmoothL1(beta=1)`，按有效标签求均值：

```text
L_now    = mean_valid rho((p_0 - y_0) / s_F)
L_future = mean_valid rho((p_1:5 - y_1:5) / s_F)

L_delta_horizon = mean_valid rho(
    ((p_k - p_{k-1}) - (y_k - y_{k-1})) / s_delta
)  # k=1..5，包含 当前→下一步

L = 1.0 * L_now + 1.0 * L_future + 0.5 * L_delta_horizon
```

三个项分别约束力的当前水平、未来轨迹和变化幅度/符号。每项单独按自己的有效元素数归一化，未来五步先使用均匀权重，避免因为标签数量不同而隐式改变任务权重。

变化项必须使用“预测下一步减预测当前步”。如果把预测当前步替换为真机实测当前力，那么 `(p_1-y_0)-(y_1-y_0) = p_1-y_1`，该项只是重加权的下一步力值损失，没有提供额外的相对变化约束。真机当前力可以用作标签，不能在 Sim 推理预测路径中作为已知输入。

本轮先不加入全维逐帧 latent MSE、cosine、旧 encoder 蒸馏、本域 Sim 重建、频谱和独立峰值项。上述决定用于建立能解释效果的起点，不代表这些辅助任务以后一定无效。

SmoothL1 是为了让第一轮变化监督对少量异常差分较稳定，不保证优于 MSE。保持其它条件不变，之后可以单独比较 MSE；不要同时换多个损失、采样和模型结构后归因于某一个改变。

**尺度与时间**

`s_F` 是真机训练轨迹中三轴力的标准差；`s_delta` 是同一连续片段内相邻真机力增量的三轴标准差。两者固定保存进 checkpoint，在验证和推理时不重估。可分别使用 0.1 N 和 0.05 N 的初始下限，避免近似常数轴的除零或过大权重；下限也应记录为超参数。

对现有 24 条训练轨迹重算的数值如下，不可当作其它划分的固定常量：

| 统计量 | Fx | Fy | Fz |
|---|---:|---:|---:|
| s_F，N | 1.690 | 1.285 | 2.859 |
| s_delta，N | 0.409 | 0.257 | 1.504 |
| s_delta / s_F | 0.242 | 0.200 | 0.526 |

当前 v3 对力值和差分都使用 `s_F`，横向变化的尺度相对较小。变化项换用自己的训练集尺度后，0.5 这一系数的含义也随之改变，不能直接与旧版 0.25 比较。

现有 v3 的 `stats['real']['scale'][3:6]` 来源是每帧增量，但 shared-latent 脚本对应位置来源是除过 dt 的变化率。新实现使用明确的新字段，例如 `target.increment_scale_n`，独立从真实增量拟合，避免混用两种物理量。

这批训练数据的有效相邻 dt 范围约 0.0081–0.2003 秒，中位约 0.1000 秒。第一轮监督每采样步的力增量，不直接除以很小的 dt。仍保留实际历史 dt 输入，报告真实时间上的延迟；这里的 +5 步不保证严格等于 0.5 秒。如果以后定义固定秒数的预测任务，需要另外设计重采样与目标时间，不能仅改损失名字。

**训练顺序**

1. 训练 `E_real + D_real`，两者均使用上述真实物理量目标。新增的当前力输出必须在这一阶段训练好；现有只输出五步的预测头不能直接当作已训练好的六步头冻结。
2. 固定 `E_real` 和 `D_real`，用 Real encoder 初始化 `E_sim`，只训练 `E_sim`，标签仍然是真机当前及未来力。
3. 冻结 decoder 参数时仍然保留 decoder 对输入 latent 的梯度，不能把 Sim 的预测头前向包在 `torch.no_grad()` 里。Real teacher 的辅助前向可以不求梯度。

两域使用同一个固定的已训练预测头，让 Sim latent 必须进入可解码真机力的表示空间。它并不保证所有 latent 坐标都一一相等，也不保证任意下游策略已经可迁移；这一步的验收以物理量预测为准。

**主任务跑通后才比较的辅助项**

- 真实历史恢复：`L_hist_real` 从当前 latent 恢复最近 15 个过去的真机力点，先排除已由 `L_now` 监督的当前点，初始权重 0.1。共享历史解码头在 Real teacher 阶段训练好，Sim 阶段冻结。目标与输出尺度均属于 Real。不要直接把旧 Sim 重建目标换成 Real 后继续按 Sim 均值/尺度反归一化。
- 流式变化：现有 17 个连续端点块可额外监督 `p_0(t)-p_0(t-1)` 对应的真实增量。初始权重 0.1，仅使用连续、未补齐且无断档的相邻端点。这和同一个端点内部未来轨迹的变化是两个指标，分别报告。
- 趋势对齐：仅对冻结 Real teacher 的趋势表示做低权重约束，先用 teacher 训练集尺度标准化，初始权重 0.03；从 0 开始的基线必须保留。预测误差未改善就不保留该项。
- 防塌缩：有效秩、第一主成分方差占比和通道相关性首先作为诊断。必要时比较小权重的方差/协方差正则，初始可用 `0.01 * (L_var + 0.01 * L_cov)`，在每个域内的独立采样块端点上计算；不要把相邻重复帧或两域偏移当作有效方差。固定非零方差阈值依赖 latent 的尺度，应参考已训练 Real teacher，不强求所有任务必须用满 32 个独立方向。单靠每个通道有方差不能证明未塌缩。

旧 `peak_loss` 对减去均值后的归一化力取绝对值，优化的是相对训练均值的偏离；它和物理单位下的 `abs(F)` 峰值不同。如果随后需要加峰值监督，应在物理力上构造有符号极值或绝对峰值，再缩放误差，并按实际时间计算峰值时刻。当前主配方不依赖该项。

**掩码与采样约束**

- `current`、`future`、历史目标都取同一配对 Real 轨迹。所有输入截至当前端点，不向模型提供未来真机力、未来运动或未来实际 dt。
- 当前有效帧使用 current mask；未来每一步使用独立的 future mask；差分只有两个端点都有效时计算。`t→t+1` 的 mask 包含 current 和第一步 future。
- 不跨轨迹、不跨时间断档，不对左侧补齐点、结尾截断点计算监督。某项没有有效元素时返回与计算图相连的有限零值。
- v3 已使用一半均匀、一半偏向变化事件的轨迹等权块采样。第一轮保留它，不额外在 loss 中重复施加强事件权重；采样策略变更单独做对照。
- 新增流式差分时，现有块的第一个前驱端点可用于差分，但它不应因此被重复计入主监督；检查 reset 处两端点的真实索引和 segment 相同。

**选模和验收**

Sim student 的主选模分数建议为 `0.25*RMSE(+1) + 0.35*RMSE(+3) + 0.40*RMSE(+5)`，每条轨迹等权、单位 N，沿用现有 future score。当前恢复误差和增量误差作为约束：要求不明显退化，约束阈值在正式比较前固定，例如相对基线容许 5%；记录未通过原因。epoch 首先按 future score 选择，不能再让 alignment score 或 Sim 自身重建分数排在预测表现之前。

报告至少包含当前 Real 力恢复、未来 +1/+3/+5 力误差、覆盖第一步的增量误差、逐轴结果、真实接触突变事件结果、流式当前预测差分、latent 有效秩与谱集中度。当前 v3 的 `future_delta_rmse_n` 同样只覆盖 +1..+5 内部差分，需要与新的完整变化定义同步。

所有 Sim 预测基线也只读取截至 t 的 Sim 力历史；先比较训练集拟合的仿真力仿射校准保持、force-only 线性 AR。Real 当前力保持只用于 Real 输入实验，不能作为 Sim 推理可使用的信息。

最小的损失对照顺序为：

| 实验 | 当前与未来真机力 | 完整变化项 | 真实历史恢复 | 趋势对齐 |
|---|---|---|---|---|
| A | 是 | 否 | 否 | 否 |
| B（推荐首个完整配方） | 是 | 0.5 | 否 | 否 |
| C | 是 | 0.5 | 0.1 | 否 |
| D | 是 | 0.5 | 否 | 0.03 |

先固定一个轨迹划分验证实现，再按轨迹做多折和多 seed 比较。既有 validation/diagnostic 已被多次查看，不能称为新的独立盲测。各项 loss 数值和它们对 encoder 的梯度范数应分别记录，权重根据实际贡献与验证结果调整。

**落地时需要联动修改的接口**

`model.py`：增加共享当前力输出，或把共享头从 15 个输出改为 18 个，外部仍单独返回 `current [3]` 与 `future [5,3]`。

`data.py`：沿用已有 Real current/future 标签，补独立的增量尺度统计；可选真实历史恢复再增加原始 Real 历史及其 mask。

`losses.py`：三个主项与独立掩码、归一化；可选辅助项独立配置。

`train.py`：教师/学生分阶段，按真实未来力误差选模型，保留逐项与梯度日志。

`metrics.py` / `runtime.py`：新增当前真实力估计和包含第一步的变化指标，明确每个输出的目标域与单位。若引入真实历史恢复，应同时改掉原有本域反归一化与本域重建指标。

Checkpoint / manifest：保存 `target_domain=real`、六步含义、新尺度、损失配置与选模规则，使用新 artifact format 和新运行目录，旧权重和策略输入不直接替换。
