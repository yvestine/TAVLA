# 旧部署 encoder 与 full_insertion_v4 训练对照

检查日期：2026-10-10。依据旧权重保存的指标、修改前备份的训练代码，以及 v4
运行 `full_insertion_v4_20261010_211558_3984721` 的参数清单、曲线和报告。
本次只读取既有结果；没有启动训练或重新执行模型评测。

## 1. 为什么旧版能保存，而现在被拒绝

旧代码先选出各折最佳结果，取最佳 epoch 的中位数，最终在 32 条训练轨迹上
重新训练并保存。保存前没有 Macro-F1 / recall 的硬性门槛。

新版要求：同一个 epoch 的四折汇总结果中，Real、Sim 各自 Macro-F1 ≥0.70，
两个类别各自 recall ≥0.60，并有末段几何评估样本。v4 没有轮次满足全部条件，
因此没有执行最终训练，报告状态为 `rejected_cv`。

0.70 / 0.60 是修改代码时新增的工程下限，未事先根据旧内部交叉验证结果校准。
旧模型各折最佳结果汇总后，Sim Macro-F1 也只有 **0.6981**，低于 0.70。
这说明“旧版能保存”不能作为“旧版曾通过当前门槛”的证据。

旧代码未保留完整 CV 曲线，因此无法确定旧配方在某个共同 epoch 是否会通过
当前门槛；不能用各折不同轮次的最佳结果替代该检查。

## 2. 训练配方具体区别

| 项目 | 旧部署 encoder | 最新 full_insertion_v4 |
| --- | --- | --- |
| 网络 | 约 49,797 参数；因果卷积、GRU、32 维 latent | 参数规模与主体结构相同 |
| 力输入 | 32 帧，XYZ 力与 XYZ 力变化率，共 6 通道 | 相同 |
| 在线 pose 输入 | 不进入 encoder；pose 仅生成离线几何标签 | 相同 |
| 基线 | 每轨迹首 20 帧各轴力中位数 | 相同 |
| 数据入口 | 备份脚本默认 `data`、`sim-data-aligned`、v2 阶段标签 | manifest 记录相同目录及标签路径 |
| 轨迹划分 | 32 条训练、8 条留出，训练内部四折 | 留出轨迹与四折轨迹名单均相同 |
| 几何训练覆盖 | 可靠的歪斜 / 对正标签内部，首次 XY<3 mm 且绝对 Z<3 mm 前截断 | 所有非 free 帧，包括阶段边界、uncertain、terminal 和最后插入 |
| 训练窗口数 | 1692 对，均有分类和几何标签 | 分类 1703 对；几何 3260 对，其中 1557 对不参与分类 |
| 训练轨迹最后 0–3 mm | 入选监督帧为 0 | 入选 332 对，包含终点保持和仍在插入的帧 |
| 归一化尺度来源 | 训练轨迹首次达标之前的全部力特征 | 训练轨迹全程力特征，包含末段 |
| 分类抽样 | 类别逆频率 × 置信度；置信度也用于损失 | 两类各占 50%；轨迹采样概率与其窗口数平方根成正比；置信度仅用于损失 |
| 几何抽样 | 与分类用同一批窗口 | 独立批，按深度、阶段、轨迹均衡 |
| 每步 batch | 128 对窗口共同计算四种损失，256 个两域输入 | 128 对分类 +128 对几何，512 个两域输入 |
| 每 epoch 更新数 | 按入选分类窗口数计算 | 按有分类标签的窗口数计算；v3 曾按较大的几何窗口数计算 |
| 损失权重 | 分类 1、配对余弦 0.15、XYZ 几何 0.12、XY 方向 0.05 | 名义系数相同，样本来源与有效优化目标已有变化 |
| 学习率 | 固定 0.001 | 5 轮预热至 0.0003，再余弦降至 0.00003 |
| AdamW weight decay | 0.0001 | 0.01，增加 100 倍 |
| 时序层 dropout | 0.10 | 0.20 |
| 分类 label smoothing | 0 | 0.05 |
| 力增益增强 | 0.9–1.1 | 0.85–1.15 |
| CV 训练 | 脚本默认最多 60 轮，连续 10 轮无改善早停 | 每折完整 100 轮 |
| 最佳轮次依据 | 两域 aligned_progress F1 与 XY 方向余弦 | 先满足分类门槛，再结合两域分类和末段 Z 误差 |
| 最终轮次 | 各折最佳为 8 / 11 / 10 / 5；中位数取整后最终 9 轮 | 无合格共同轮次，未进行最终训练 |
| 保存 | 完成最终训练即保存 | CV 达标才生成最终 encoder；失败保留报告和 CV 权重 |

“六通道”指三维力及其变化率，不是三维力加三维力矩。32 帧历史在这次修改前
就已存在。当前配方还没有 encoder 的 action 监督；它不直接输出控制动作。

旧 artifact 未记录完整命令行和数据 SHA256。表中的旧预算、batch 等可配置参数
来自备份脚本默认值；最终训练 9 轮、窗口数、轨迹名单及验证结果来自实际权重。
两版路径一致不能证明历史数据文件的内容完全未发生变化。

## 3. 指标必须按评估来源解释

| 结果来源 | 真机 Macro-F1 | 仿真 Macro-F1 | 说明 |
| --- | --- | --- | --- |
| 旧最终模型，8 条留出轨迹、370 对入选窗口 | 0.8651 | 0.8138 | 最终在 32 条训练轨迹上训练 9 轮后评估 |
| 旧内部四折，各自最佳 epoch 8 / 11 / 10 / 5 的结果汇总 | 0.7305 | 0.6981 | 不同折使用不同 epoch；不等于共同轮次的指标 |
| v4 内部四折共同 epoch 18，1703 对分类窗口 | 0.6973 | 0.6626 | 该轮综合选择分最高，但分类门槛未达标 |
| v4 最终模型的留出测试 | 未执行 | 未执行 | CV 未达标，最终模型未生成 |

旧与新内部 CV 的轨迹划分相同，但窗口数和选轮方式仍不同。因此，旧留出
0.8138 与新 CV 0.6626 不能直接解释为同一指标下降了 15 个百分点。
旧内部 CV 的汇总 0.6981 表明，困难轨迹上的分类泛化在旧配方中就没有留出
0.8138 那么高。旧第二折的 Real / Sim Macro-F1 分别只有 0.5850 / 0.6232。

## 4. 补齐末段之后仍存在什么问题

旧审计记录显示：40 条轨迹在 XY<3 mm 且绝对 Z<3 mm 下有 414 帧，其中
进入旧窗口训练的监督帧为 0。这是已确认的数据覆盖缺口。
旧模型报告的高分类分数主要评价截断前的可靠阶段，不能证明末段深度已学会。

v4 在共同 epoch 18 的内部 CV 中，仿真 `aligned_progress` 几何结果如下。
深度分组使用绝对 Z；表内 Z 均值是相对示教终点 tip 的有符号 Z。

| 深度分组 | 窗口数 | 目标 Z 均值（mm） | 预测 Z 均值（mm） | Z MAE（mm） |
| --- | --- | --- | --- | --- |
| 0–3 mm | 114 | 0.97 | 6.23 | 5.26 |
| 3–5 mm | 49 | 3.95 | 6.33 | 2.40 |
| 5–8 mm | 74 | 6.39 | 6.41 | 1.17 |
| 8–10 mm | 46 | 8.93 | 6.35 | 2.60 |

预测均值集中在约 6.3 mm，说明该轮的辅助几何头对这些深度组的区分不足。
这是现有报告中的观测，不等于 latent 完全没有深度信息，更不能直接当作策略
action 或闭环插入失败的因果证据。

可能的原因包括：

1. 新增几何任务与原分类 / 域对齐任务通过同一 latent 更新，优化存在相互影响。
   名义 loss 系数相同不代表任务的有效影响相同。
2. 仅由力历史预测相对终点的绝对 XYZ，在不同接触条件下可能有歧义。
   加入姿态生成的标签能够扩展监督，但不会自动使力信号包含充分的几何信息。
3. 一次同时改变覆盖、采样、归一化、正则化、学习率和选轮规则，当前结果
   无法分离各项改动的贡献。v4 的正则化减少了极端的训练过拟合，却没有使
   仿真 CV Macro-F1 达到门槛；这并不能证明某个单项调整有效或无效。

这些原因需要在相同评估口径下控制变量验证。下一步应建立可复现的旧配方
基线，再单独加入末段有效监督，保留共同的轨迹划分与末段报告；质量门槛应
根据可比较的基线确定。继续增加轮数或降低门槛都不能代替末段能力检查。
